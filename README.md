# Kontainer: Mobile application for Portainer
A mobile app for managing Docker containers, Kubernetes environments, and Portainer instances with AI-powered assistance via MCP.

## Features

### Container Management
- **Containers**: View, start, stop, restart, and remove containers
- **Images**: Pull, remove, and manage Docker images
- **Volumes**: Create and manage persistent storage volumes
- **Networks**: Create and configure Docker networks
- **Services**: Manage Docker Swarm services

### Portainer Integration
- **Multiple Instances**: Connect to multiple Portainer servers
- **Authentication**: Support for Basic Auth and API Key authentication
- **SSL/TLS**: Custom certificates and SSL error handling
- **Stacks**: Deploy and manage Docker Compose stacks

### Kubernetes Support
- **Environments**: Connect to Kubernetes environments via Portainer
- **Namespaces**: View and manage Kubernetes namespaces
- **Deployments**: Monitor and manage deployments
- **Pods**: View pod status and details
- **Services**: Manage Kubernetes services
- **ConfigMaps & Secrets**: View configuration resources

### MCP AI Assistant
- **AI Chat**: Chat with AI to manage containers using natural language
- **MCP Proxy Server**: HTTP wrapper for portainer-mcp exposing MCP via SSE
- **Connection Testing**: Verify MCP server credentials before saving
- **Multi-provider Support**: OpenAI, Claude, Gemini, Ollama, and custom endpoints
